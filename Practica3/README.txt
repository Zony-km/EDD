# Práctica 3 - Pilas 

Este proyecto consiste en la implementación de una estructura de datos tipo **pila (Stack)** utilizando referencias (nodos) en Java, cumpliendo con las operaciones básicas en tiempo constante O(1).

A partir de esta implementación, se desarrollan dos aplicaciones principales:

## Simulador de Asteroides

Dado un arreglo de números enteros que representan asteroides (donde el valor absoluto indica el tamaño y el signo la dirección), se simulan las colisiones entre ellos. Se utiliza una pila para determinar qué asteroides sobreviven después de todas las interacciones.

## Validador de HTML

Se implementa un método que verifica si una cadena con etiquetas HTML está correctamente balanceada, asegurando que cada etiqueta de apertura tenga su correspondiente etiqueta de cierre y que estén correctamente anidadas.
